## 🎯 About

This repository documents my learning journey through a comprehensive Python Development program, covering the foundations of software engineering, mathematical principles behind machine learning, classical ML algorithms, and modern deep learning architectures.

The goal is to build a strong theoretical foundation, develop practical implementation skills, and understand how AI systems are designed, trained, evaluated, and deployed.

## 📚 Curriculum

### 01. Python & Mathematical Foundations

Building a solid foundation in programming, software design, and mathematics.

- **Python:** Core language concepts, object-oriented programming (OOP), SOLID principles
- **SQL:** Relational databases, queries, and data manipulation
- **Linear Algebra:** Vectors, matrices, matrix operations, and vector spaces
- **Calculus:** Limits, derivatives, gradients, and optimization fundamentals

### 02. Data Science & Classical Machine Learning

Learning to analyze data, extract meaningful insights, and implement classical machine learning algorithms.

- **NumPy:** Numerical computing and vectorized operations
- **Pandas:** Data manipulation, cleaning, and exploratory data analysis
- **Probability:** Random variables, probability distributions, and statistical reasoning
- **Regression:** Linear and nonlinear prediction models
- **Ensemble Methods:** Combining models to improve predictive performance
- **Support Vector Machines (SVMs):** Classification and regression
- **Clustering:** Unsupervised learning and grouping similar data points
- **Principal Component Analysis (PCA):** Dimensionality reduction and feature extraction

### 03. Deep Learning & Applied AI

Exploring neural networks, modern AI architectures, large-scale data processing, and production-oriented ML workflows.

- **PyTorch:** Tensors, automatic differentiation, neural networks, and model training
- **Convolutional Neural Networks (CNNs):** Deep learning for computer vision
- **Transformers & LLMs:** Attention mechanisms, transformer architectures, and large language models
- **Diffusion Models:** Generative modeling and image generation fundamentals
- **Apache Spark:** Distributed data processing and large-scale analytics
- **MLOps:** ML lifecycle management, reproducibility, experiment tracking, and deployment workflows

## 🧠 Learning Philosophy

My approach is built around four principles:

- **Understand, don't memorize.** Focus on the reasoning behind algorithms, mathematical concepts, and engineering decisions.
- **Implement from scratch when useful.** Strengthen understanding by translating theory into code before relying entirely on high-level abstractions.
- **Connect theory with practice.** Apply mathematical foundations to real machine learning problems.
- **Build reproducible solutions.** Keep code organized, document experiments, and follow sound software engineering practices.

## 🚀 Long-Term Goal

To develop the skills required to design, implement, and understand modern AI systems — from mathematical foundations and classical machine learning to deep learning, generative models, and production-oriented ML engineering.
